WebsiteDownloader Universal

Una eina per recopilar pàgines d'un web i reunir-les en un únic fitxer HTML consultable sense Internet.

1. Instal·lació (només una vegada)

Mostra la barra de preferits amb Ctrl + Maj + B. Després arrossega aquest botó blau fins a la barra (no hi facis clic aquí):

Baixar aquesta web

Si no pots arrossegar-lo: i enganxa'l a l'URL d'un preferit nou.

2. Ús

  1. Obre la pàgina web que vols recopilar.
  2. Prem el preferit Baixar aquesta web de la barra.
  3. Tria una pàgina, una secció o el mateix lloc web, i el màxim de pàgines.
  4. Prem Comença. Al final es descarrega un únic HTML. Pots obrir-lo sense Internet i imprimir-lo a PDF amb Ctrl + P.

Per exemple, per a un manual pots començar des del seu índex, triar «Aquesta pàgina i els enllaços d'aquesta secció» i posar un límit de 50 pàgines.

Limitacions: funciona millor amb webs de documentació tradicionals. Només segueix enllaços del mateix domini; no pot saltar restriccions d'accés ni garantir que copiï pàgines amb contingut dinàmic. Pot haver-hi imatges o recursos que no es puguin incorporar. Comprova el recompte i les incidències del fitxer final. Fes-lo servir només per a continguts que tens dret a desar.
